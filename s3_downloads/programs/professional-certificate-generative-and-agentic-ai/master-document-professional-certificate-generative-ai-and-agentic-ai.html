2. PROGRAMME PURPOSE AND OUTCOME

The programme is designed for learners who want to move from using Generative AI tools to building, evaluating and deploying AI-powered applications and agentic systems.

Learners build practical capability across:

  • Python and developer/cloud readiness for AI application development
  • Large Language Model (LLM) application engineering
  • Retrieval-Augmented Generation (RAG)
  • LLM evaluation, quality and reliability
  • AI agents and multi-agent workflows
  • Tool use, orchestration and human approval workflows
  • Deployment and production-oriented AI application practices
  • Applied Labs, portfolio builds and a capstone

The programme is hands-on. Learners are expected to write and debug code throughout the programme.

3. ELIGIBILITY CRITERIA

An applicant should meet the following requirements:

1.  Bachelor’s degree from a recognised university.

2.  Mathematics studied in Grade 12.

3.  Current basic programming ability in at least one programming language.

The programming ability may have been developed through work, academic study or personal projects.

Applicants should be able to:

  • read, understand, write and modify basic programs independently;
  • use core programming concepts such as variables, conditions, loops, functions and basic data structures;
  • turn a simple problem or requirement into working code; and
  • identify and fix basic programming errors without requiring step-by-step guidance.

Work Experience

Work experience is preferred, but not mandatory.

Recent graduates may apply if they meet the academic requirements and can demonstrate current basic programming ability.

Python and AWS

Prior knowledge of Python and AWS is helpful but not required.

The initial foundation helps programmers transition to Python and cloud/developer tools used in the programme.

Critical Readiness Requirement

The programme is not designed to teach programming from the beginning.

Applicants who have never programmed, or who cannot currently write basic programs independently, should not be positioned as ready for this programme.

Final admission is subject to the applicable institutional review of the information and documents submitted by the applicant.

6. PROGRAMME STRUCTURE

The programme follows one integrated cohort-based learning journey of approximately 35 weeks.

Module 1 – Foundations of AI Development | Weeks 1–8

Module 1 begins with a five-week foundation and then moves into building and deploying an AI application.

 

The foundation supports existing programmers who are moving to Python and cloud tools. It is not a beginner programming course.

Modules 2–7

 

The curriculum is indicative and may be updated based on academic and technical assessment and evolving industry requirements.

7. WHAT LEARNERS BUILD

The approved programme description is:

Applied Labs, three portfolio builds and a capstone.

The portfolio builds currently described in the programme enablement material are:

1. AI Workbench

An AI assistant developed into a production-style service.

2. Daily Planet AI Desk

A research assistant designed to cite its sources and avoid unsupported answers.

3. Mission Control

A multi-agent system that investigates a problem and incorporates human approval before acting.

Capstone

Learners bring the programme learning together into a production-style system relevant to their own domain.

Counselling guardrail: Do not quote unapproved project counts such as “20 projects” or “30 projects”.

9. LEARNING METHODOLOGY

The programme follows a flipped-classroom, hands-on learning model.

Learners build conceptual understanding before the live session and use live time for building, demonstrations, questions and deeper discussion.

10. WEEKLY TIME COMMITMENT

Learners should plan for approximately 9–10 hours per week across:

  • self-paced learning;
  • videos/readings;
  • hands-on Applied Labs;
  • coding and practice;
  • live sessions; and
  • project/capstone work as applicable.

The first five weeks have a heavier live-session structure because there are sessions on both Saturday and Sunday.

Counsellors should discuss the time commitment before payment and should not understate the effort required.

12. ASSESSMENT AND PROGRAMME COMPLETION

The programme uses an application-oriented assessment model.

To successfully complete the programme and receive the certificate, learners must:

  • complete all quizzes; and
  • complete the capstone project with at least a “Fair” grade.

“Fair” Grade

“Fair” is the minimum acceptable academic performance level for the capstone.

Do not invent:

  • a percentage equivalent;
  • a numerical marks cut-off; or
  • a detailed rubric unless the academic team has formally published one.

Detailed project evaluation criteria, submission requirements and academic instructions are communicated by the academic team during the programme.
